## Các bước nghiệm thu còn lại

- Chạy fresh checkout theo README với Linux Docker daemon; xác minh build image, migration, API/worker/web và `pnpm smoke` qua cùng origin.
- Chạy full Go tests/Testcontainers và ca DB mất kết nối rồi phục hồi.
- Chạy ba workflow trên GitHub và bổ sung link run thực tế.
- Sinh, đối chiếu mockup và commit 18 baseline trong đúng `PLAYWRIGHT_IMAGE`; thêm phép so ảnh và chạy lại hai lần để xác nhận ổn định.

## Bàn giao các phase sau

- CSP vẫn có `unsafe-inline` theo exception P01; P06 chốt nonce hoặc hash-based CSP phù hợp cách render landing.
- Vault pill, shell/detail/settings và dữ liệu tìm kiếm là bản xem trước chỉ đọc. P02 nối auth/locale người dùng, P03 nối vault, P04 nối dữ liệu thật.
- River `noop` chỉ chứng minh lifecycle; P05 triển khai embedding thật. Provider `noop` không quảng cáo semantic khả dụng.
- Primitive UI hiện viết tay; các phase sau mở rộng bằng Radix khi cần dialog/popover/dropdown, giữ token và hành vi bàn phím.
- Landing chưa có crypto thật; chỉ đổi copy sang khẳng định mã hoá sau khi vault được triển khai và xác minh.
