### Hai lỗi sản phẩm phát hiện và sửa trong lượt này

1. **Mất thông báo “Login password updated” sau khi đổi password.** Đổi password thay session → bump session epoch → query `['auth','me',epoch]` đổi key và bắt đầu rỗng → `RouteGuard` thay cả cây bằng loading frame → trang settings unmount và `useState` giữ notice bị huỷ. Sửa ở `apps/web/features/auth/session-provider.tsx`: khi `session_changed` origin local (cùng user, cookie mới), chuyển snapshot `me` sang key epoch mới rồi invalidate; origin remote vẫn bắt đầu rỗng vì có thể là tài khoản khác. Thêm phòng ngự ở `apps/web/features/auth/route-guard.tsx`: chỉ chặn bằng loading frame khi chưa có `me` để render. (`me` một mình chưa đủ — lượt sửa chỉ ở RouteGuard vẫn fail, xác nhận nguyên nhân nằm ở query key.)
2. **Callback `identity_conflict` mời “Try again”.** Retry cùng provider luôn conflict lại; đổi sang `oauthCallback.backToLogin` trỏ về `/app/auth/login` (`apps/web/features/auth/forms/oauth-callback.tsx`).
