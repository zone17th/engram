## Rollback

Theo plan mục 7 và [runbook](../../runbooks/search-semantic.md): `pg_dump` trước migration `0008`/`0009` (forward-only; binary rollback phải tương thích schema); deploy P05 với `SEARCH_SEMANTIC_ENABLED=false` nên lexical chạy độc lập semantic; sự cố provider không cần rollback (breaker + `degraded`), tắt hẳn bằng `SEARCH_SEMANTIC_ENABLED=false` rồi redeploy `api` + `worker`; đổi model sau bootstrap là cutover 7 bước thủ công, rollback generation trong `SEARCH_ROLLBACK_WINDOW` (mặc định `168h`) khi bản retired đã catch up, `drop` chỉ sau cửa sổ và có `--accepted-evidence`; `0010` (nếu có) chỉ deploy sau report benchmark. Sự cố dữ liệu không chữa bằng reset vault: sửa forward hoặc restore DB (§10.5).
